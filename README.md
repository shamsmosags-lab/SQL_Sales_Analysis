# SQL Sales Analysis

A beginner-friendly SQL project focused on analyzing sales data using SQLite and Python to extract useful business insights.

## Project Overview

This project demonstrates how SQL can be used to analyze structured sales data and answer common business questions.

The analysis covers product performance, category performance, sales quantities, and monthly sales.

## Business Problem

The business needs to understand which products and categories perform best and identify stronger sales periods in order to support better business decisions.

## Solution

I created a small sales database using SQLite and used SQL queries to:

* Calculate total sales
* Analyze sales by product
* Analyze sales by category
* Analyze sales by month
* Rank products by total sales
* Identify the top-performing products

## SQL Analysis

The project uses SQL concepts including:

* SELECT
* SUM
* GROUP BY
* ORDER BY
* LIMIT
* Aggregate functions

## Visualization

A bar chart was created using Python and Matplotlib to visualize sales performance by product.
